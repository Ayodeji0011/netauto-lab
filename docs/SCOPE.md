# Lab Scope

This repository documents practical networking and infrastructure work, with emphasis on reproducible labs and evidence-based documentation.

## Evidence standard

- **Completed:** directly built, configured or tested by me.
- **Academic:** performed as coursework/SIWES/project work.
- **Experimental:** explored or prototyped; not presented as production deployment.
- **Concept:** design work without claiming implementation.

No credentials, private keys, personal identifiers or live access tokens belong in this repository.
