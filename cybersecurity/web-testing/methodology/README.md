# Web Application Testing Methodology

My web application security testing workflow covers:

1. Reconnaissance and attack-surface identification
2. Endpoint discovery
3. Parameter identification
4. Request interception and modification
5. Authentication and authorization testing
6. Input validation testing
7. XSS testing
8. IDOR/access-control testing
9. LFI testing
10. Open-redirect testing
11. Automated discovery with appropriate tooling
12. Manual verification of findings
13. Evidence collection
14. Risk assessment and remediation recommendations

Testing is performed only against applications and assets where
authorization exists, or against intentionally vulnerable labs.
