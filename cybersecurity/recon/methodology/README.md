# Reconnaissance

Hands-on reconnaissance experience using Linux security tooling and
web-security workflows.

## Activities

- Subdomain and asset discovery
- DNS reconnaissance
- Service and port discovery
- HTTP endpoint discovery
- Technology identification
- Parameter discovery
- Endpoint enumeration
- Nmap-based network/service enumeration
- FFUF-based content and endpoint discovery
- Recon-ng workflows
- Custom shell automation

## Tools

- Nmap
- FFUF
- Recon-ng
- Burp Suite
- Linux command-line tooling
- Custom Bash/Python automation

Raw reconnaissance results for third-party targets are intentionally
excluded from this public repository.
