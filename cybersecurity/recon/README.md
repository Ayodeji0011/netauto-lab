# Reconnaissance

Practical reconnaissance and attack-surface discovery work using Kali Linux and common security tools.

## Tools

- Amass
- HTTPX
- Nuclei
- Naabu
- Dirsearch
- ParamSpider
- Arjun
- SecLists

## Workflow

Typical reconnaissance work involves:

1. Scope identification
2. Asset discovery
3. DNS/subdomain enumeration
4. Service discovery
5. HTTP probing
6. Technology identification
7. Endpoint discovery
8. Vulnerability scanning
9. Manual validation

Results are treated as leads that require manual verification rather than automatically assuming a scanner finding is a vulnerability.
