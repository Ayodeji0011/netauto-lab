## Networking

- LAN configuration and troubleshooting
- WLAN configuration and troubleshooting
- IPv4 addressing and subnetting
- DHCP
- VLAN design and segmentation
- Cisco router and switch configuration
- RIP and OSPF routing
- Access Control Lists (ACLs)
- Cisco Packet Tracer
- Wireshark packet analysis
- OSI model and packet-flow analysis

### Documented lab example

A small office network was designed in Cisco Packet Tracer with three VLANs for administrative staff, students and guests. Routing was configured with OSPF and traffic was subsequently examined with Wireshark.
