# Structured Cabling, CCTV, Fiber and PoE

Hands-on networking and ICT infrastructure work carried out during SIWES and technical training.

## Structured Cabling

Work included installation and organization of network cabling using:

- Cat5e
- Cat6
- RJ45 connectors
- Patch panels
- Network racks
- Cable testing
- TIA/EIA-568 termination standards

The work involved cable preparation, termination, testing and troubleshooting of physical network connections.

## CCTV Networking

CCTV installation and network integration work included:

- Camera installation
- Camera network connectivity
- PoE connections
- Network infrastructure integration
- CCTV coverage for offices, lecture halls and other facilities
- Troubleshooting camera/network connections

## Fiber Optic Networking

Fiber optic infrastructure was used for longer-distance CCTV and network connections.

Work included:

- Fiber optic cable installation
- Fiber-to-network connectivity
- Media converter deployment
- Testing and troubleshooting fiber links

## PoE

Power over Ethernet was used where appropriate to provide both network connectivity and power to networked devices such as IP cameras.

## Solar-Powered CCTV

The training also exposed me to solar-powered CCTV installations, including the relationship between the power system, camera equipment and network infrastructure.
