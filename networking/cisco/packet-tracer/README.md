# Enterprise Three-Office Network — Cisco Packet Tracer

A Cisco Packet Tracer network design built around three separate office sections.

## Project

The topology contains three office networks, with each office using a router and switch together with its connected end devices.

The project was built to practise:

- Network topology design
- Router and switch configuration
- IP addressing
- Subnetting
- LAN connectivity
- Inter-office communication
- Basic enterprise network structure
- Troubleshooting and verification

## Topology

The network is divided into three office sections:

- Admin
- Accounts
- Third Office

Each office contains:

- 1 router
- 1 switch
- Connected network/end devices

The Packet Tracer topology is stored in:

`enterprise-three-office-network.pkt`

## Skills Demonstrated

- Cisco Packet Tracer
- LAN design
- Router configuration
- Switch configuration
- IP addressing
- Subnetting
- Inter-network connectivity
- Network troubleshooting

## Verification

Connectivity and configuration can be tested directly by opening the Packet Tracer file and checking the device configurations and end-to-end communication.
