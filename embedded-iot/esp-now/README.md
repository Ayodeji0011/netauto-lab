# ESP-NOW Emergency Communication System

## Project

**Design and Implementation of a Decentralized Multi-Hop Emergency Communication System for Smart Campus Safety Using ESP-NOW Protocol**

A decentralized emergency communication prototype using ESP32 nodes and ESP-NOW for local wireless communication.

## Node Structure

The system uses multiple node roles including:

- Emergency node
- Relay node
- Security node

## Main Components

- ESP32
- NEO-6M GPS
- DS3231 RTC
- Keypad
- OLED display
- ESP-NOW communication

## Features

- Emergency message transmission
- Multi-hop relay
- Node-to-node communication
- GPS location information
- Message identification
- Acknowledgement-based communication
- Local web interface
- Failover communication logic

## Security

The project investigated secure packet communication and included security mechanisms in the system design. Experimental firmware used a lightweight demonstration mechanism; this should not be interpreted as a production cryptographic implementation.
