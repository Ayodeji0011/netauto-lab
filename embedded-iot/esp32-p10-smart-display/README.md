# ESP32 P10 Smart Display

This project is an ESP32-based smart display using red P10 HUB12 LED panels.

## Current hardware work
- 3 panels across the top and 3 across the bottom
- HUB12 interface
- Shared CLK/LAT/OE/address control
- Dual data paths
- Direct/bit-banged display scanning
- Custom 5x7 and larger fonts
- ESP32 Wi-Fi
- Local HTTPS web interface

The display project has also included Text-to-Text, Speech-to-Text, Text-to-Speech, Speech-to-Speech, Firebase control experiments and DFPlayer/PAM audio integration.

Pins and source code will be documented with actual tested versions.
